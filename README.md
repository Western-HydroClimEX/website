# HydroClimEX Lab website

Static website of the Hydroclimate Extremes and Climate Change Lab (HydroClimEX), Department of Civil and Environmental Engineering, Western University. Led by Professor M. Reza Najafi.

Plain HTML, CSS and JavaScript, with no build step. Served with GitHub Pages from the `main` branch.

To update: edit the HTML pages, commit and push to `main`. The site refreshes within a minute or two.

Photos, figures and logo: HydroClimEX Lab. Satellite imagery and animations: NASA, NOAA and USGS, public domain. Stock footage: Pexels contributors, Pexels licence.
